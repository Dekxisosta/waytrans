Waytrans translates
right on your screen

Snip any foreign text and the translation appears directly over the original words. No notification toasts, no looking away.

click the text box
今日はいい天気ですね。一緒に行きましょう。
It's lovely weather today. Let's go together.
今日はいい天気ですね。一緒に行きましょう。
INSTALL

Clone, run the installer, then fetch the Japanese models.

git clone https://github.com/remsysc/waytrans.git
cd waytrans && ./install.sh
waytrans --setup-models

Or with pip: pip install --user .

View on GitHub Keybindings

slurp

Drag a box around the text.

grim

Captures just that region.

ImageMagick

Optional 2x upscale and grayscale.

Tesseract

OCR with horizontal and vertical CJK.

translate-shell

Translates the extracted text.

Overlay

Drawn over the original via GtkLayerShell. Also copied with wl-copy.

Built for immersion

Live translation

Toggle it on and waytrans watches a dialogue box or manga panel, spots new text by perceptual hashing, and updates in place.

Click-through

In live mode the overlay passes mouse input through, so you keep clicking to advance dialogue.

In-place overlay

Anchored to the exact screen coordinates you selected, multi-monitor aware.

Japanese and CJK

Handles jpn+jpn_vert, strips OCR spacing artifacts, and supports tessdata_best models.

Lightweight

Native Wayland tools. No Electron, no web runtime.

Graceful fallback

Without Layer-Shell it falls back to notify-send. Click or press Esc to dismiss.

Bind it. Use it.
